# Cold-Email-Generator-using-Generative-AI-LLaMA-via-Groq-API-
A Streamlit app that uses Groq’s API with LLaMA 3.3 70B to generate personalized cold emails. Users input role, industry, and tone, and the app creates high-quality outreach emails in real time using generative AI. Ideal for job seekers, founders, and sales professionals.
